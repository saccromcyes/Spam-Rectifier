Is this text message spam? Ask three models.

A Naive Bayes classifier written from scratch, a sentence-embedding model, and a large language model each judge the same message, and each shows why. Trained and tested on 5,574 real SMS messages.

words that point to spam words that point to a normal message, according to Naive Bayes

Which model should you ship?

All three models are scored on the same held-out messages they never saw in training. For spam filtering, false positives matter most: a real message hidden as spam costs more than a spam message that gets through.
